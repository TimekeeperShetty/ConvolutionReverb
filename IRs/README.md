# Impulse responses

Put a few test IRs here so everyone tests with the same files.

- Keep them short (a few seconds) and in `.wav` format.
- Only commit IRs whose license allows redistribution. Note the source and license of each one below.

Free sources:
- OpenAIR library: https://www.openair.hosted.york.ac.uk/
- Voxengo free IR pack: https://www.voxengo.com/impulses/
